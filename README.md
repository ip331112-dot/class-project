# Saffron & Stone / Fieldnote Travel

A responsive two-page Bootstrap project based on the GOMYCODE checkpoint requirements.

## Pages

- `index.html` is **Saffron & Stone**, the fictional restaurant site. It has a Bootstrap navbar, hero, three-item menu grid, two-column story section, contact form, and footer.
- `travel.html` is **Fieldnote Travel Co.**, the travel-agency landing page. It has destination cards, a Bootstrap accordion for tour packages, a contact form with a destination field, and footer.

Both pages use Bootstrap 5.3.3's grid and components, with custom styles in `styles.css`. The forms are front-end demonstrations only: they validate in the browser, show a confirmation message, and do not send or store submissions.

## Open locally

Open `index.html` in a browser, or open this folder in Visual Studio Code and use the Live Server extension. Bootstrap, icons, fonts, and photography are loaded from CDNs, so an internet connection is needed to display those assets.

## Publish with GitHub Pages

Create a public GitHub repository, add these project files, then enable GitHub Pages from the repository's `main` branch. The restaurant site loads from `index.html`; `travel.html` is linked from both pages.
